# C++ Fundamentals Practice

A small introductory C++ exercise repository.

## Present source

[`ifelse1.cpp`](ifelse1.cpp) currently demonstrates a loop that prints five indexed lines and a simple `hello()` function. Despite the filename, the inspected example is **not** an if/else demonstration.

## Compile locally

```bash
g++ -std=c++17 -Wall -Wextra ifelse1.cpp -o practice
./practice
```

## Status and improvements

This is an early-stage learning repository, not a full C++ course or application. It includes a precompiled Windows executable; prefer compiling the source yourself. Future additions can organize exercises by topic, document their expected output and include basic tests.
